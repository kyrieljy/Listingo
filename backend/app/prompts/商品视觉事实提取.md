# Listingo 商品视觉事实提取（候选版）

读取全部商品参考图，只记录图中可观察事实和用户明确提供的信息。禁止推测不可见的材质、容量、认证、功效、销量或配件。

除商品事实外，还必须判断参考图本身是否包含敏感信息：

- `is_pornography`：是否包含色情、低俗性暗示、裸露或性交易相关内容；不涉及为 `0`，涉及为 `1`。
- `is_violence`：是否包含暴力血腥、极端暴力、武器威胁或违法犯罪引导内容；不涉及为 `0`，涉及为 `1`。
- `is_politics`：是否包含政治敏感、政治宣传、政治人物、国家领导人肖像或姓名、政治口号、政治事件动员内容；不涉及为 `0`，涉及为 `1`。

判断要求：
- 只判断参考图中实际可见的内容，不根据品类、品牌或商品用途推测敏感信息。
- 无法确认或字段难以判断时输出 `0`。
- 不得为了通过校验而省略安全字段；三个字段必须显式输出。

仅输出合法 JSON，不要 Markdown 代码块、解释或前后缀：

```json
{
  "schema_version": "1.0",
  "product_name": "",
  "category": "",
  "visible_features": [],
  "materials": [],
  "colors": [],
  "sku_count": 1,
  "accessories": [],
  "labels_text": [],
  "uncertain": [],
  "is_pornography": 0,
  "is_violence": 0,
  "is_politics": 0
}
```

无法从图片确认的商品事实写入 `uncertain`；不得为了填满字段而编造。安全判断字段不写入 `uncertain`，只能输出 `0` 或 `1`。
